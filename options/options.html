Backup Otomatis

Tiap backup menulis file formpilot-backup-<tanggal>.json ke folder pilihanmu (10 terakhir disimpan). Tip: pilih folder yang tersinkron OneDrive/Drive agar backup ikut ke cloud.

Perbarui Profil Otomatis

"Profile serupa" = URL pattern cocok dan ada field yang sama dengan hasil capture — maksimal 5 teratas, sama seperti daftar tombol 🔄 Perbarui. Field profile ditimpa dengan hasil capture terbaru dan hasilnya dilaporkan di panel/popup. Default mati karena efeknya langsung menulis data — nyalakan hanya bila alur kerjamu memang selalu menimpa profile serupa saat capture ulang.

Update Otomatis

Extension yang dipasang Load unpacked tidak bisa memasang versi baru sendiri — yang dilakukan fitur ini adalah membandingkan versi terpasang dengan versi di sumber (berkas berisi field version, mis. manifest.json di repo GitHub), lalu memberi tanda & membuka halaman unduhannya. Setelah mengunduh: ganti isi folder extension → ↻ Reload di chrome://extensions → refresh tab target.

Keamanan

Saat aktif, nilai field sensitif (password) dienkripsi AES-GCM dengan kunci dari passphrase — data di storage, export JSON, dan file backup ikut terenkripsi. Passphrase tidak bisa di-reset: kalau lupa, nilai terenkripsi tidak dapat dipulihkan. Passphrase diingat selama halaman/tab terbuka saja, dan saat profil dengan field terenkripsi dipakai Fill, panel akan memintanya sekali per sesi.

Zone Berbahaya

📘 Panduan Cepat

1. Simpan form (Capture)

  • Isi form di halaman target seperti biasa.
  • Klik 📷 Capture — lewat popup atau panel FP di pojok kanan bawah.
  • Beri nama → Simpan profile. Kalau ada profile serupa, muncul tombol 🔄 Perbarui untuk menimpa data lama.

2. Isi ulang form (Fill)

  • Buka form kosong yang URL-nya cocok.
  • Klik Fill — field terisi otomatis (garis hijau). Yang gagal dilaporkan lengkap dengan alasannya.
  • Upload file memang diisi manual (batasan browser); sisanya otomatis.

3. Kelola profile

  • Edit — ubah selector/nilai per field, URL pattern, tag & catatan.
  • Duplikat / Hapus tersedia di tiap baris; nama otomatis unik gaya Windows.
  • Grup terbentuk otomatis dari hostname saat capture; bisa ditambah/rename/hapus di bagian Grup.
  • Tag opsional — isi manual di editor; memunculkan dropdown filter tag.
  • Filter di Daftar Profile bisa menyentuh nilai field (mis. nomor quote tertentu).

4. Nilai dinamis & backup

  • Nilai field bisa memakai placeholder: {{today}}, {{today+30}}, {{time}}, {{timestamp}}, {{uuid}}.
  • Export JSON secara rutin, atau aktifkan Backup Otomatis ke folder tersinkron.
  • Pengaturan "grup sesuai URL" mengatur daftar di popup & panel cepat: hanya grup yang cocok dengan halaman aktif yang tampil.

Ganti Base URL Massal

Ganti origin (protokol + domain + port) pada URL Pattern banyak profile sekaligus — misal saat aplikasi pindah domain (staging → produksi). Path pada pattern tetap dipertahankan, dan profile dengan origin lain tidak tersentuh.
